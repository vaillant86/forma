# Forma - Geometric Puzzle Game #

Forma is a minimalist, challenging geometry puzzle game inspired by the classic Tangram. The core objective is to arrange a set of geometric shapes to perfectly fill a target silhouette.

## Features & Game Mechanics ##
- **Geometric Variety:** Utilize an assortment of pieces including Squares, Rectangles, Triangles, L-Shapes, and Trapezoids.
- **Pure Logic Challenge:** To elevate the difficulty, all pieces are rendered in a uniform dark grey color. Players must rely entirely on spatial awareness and geometric reasoning rather than color matching.
- **Decoy Elements:** Advanced stages introduce fake/decoy pieces that do not fit the silhouette, designed to challenge your deductive skills.
- **Grid Magnet System:** An automated snapping grid ensures smooth, precise placement of shapes.

## Controls ##
- **Left-Click & Drag:** Grab and move a piece around the screen.
- **Right-Click:** Rotate the selected piece clockwise by 90 degrees.
- **UI Buttons:** Easily access the main menu, reset the current level, or advance to the next puzzle upon victory.

## Built With ##
- **Godot Engine 4** - A powerful, open-source 2D and 3D game engine.

## How to Run the Game ##
You don’t need to install the Godot Engine editor to play the game. Pre-compiled standalone executables can be generated using Godot's export presets.

## Running Pre-compiled Binaries: ##
1. **Download** the compiled release build folder matching your operating system (Windows, Linux, or macOS).
2. **Extract** the zip archive content to a directory of your choice.
3. **Launch the Executable:**
- **Windows:** Double-click forma.exe.
- **Linux:** Run the executable binary (e.g., ./forma.x86_64). Ensure it has executable permissions (chmod +x forma.x86_64).
- **macOS:** Launch the exported .app bundle.

## Compiling / Exporting from Source (Optional): ##
If you have the source files and wish to compile the binaries yourself:
1. Open **Godot Engine 4**.
2. Import and open the project directory.
3. Navigate to **Project > Export** from the top menu.
4. Choose your target platform preset (Windows, Linux, macOS).
5. Click **Export Project** and select your output destination.
